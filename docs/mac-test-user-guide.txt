TierFlow macOS 测试版 0.2.7

选择版本
Apple 芯片（M 系列）：arm64；Intel 芯片：x64。
在苹果菜单 → 关于本机查看芯片类型。需要 macOS 13 或更新版本。

首次安装
1. 完整解压 ZIP，不要只取出 TierFlow.app。
2. 双击 Install-TierFlow.command。脚本将应用复制到你个人的 Applications（应用程序）文件夹，并在本机生成测试签名；无需开发者账号、管理员密码或下载安装依赖。
3. 安装完成会打开应用所在文件夹并尝试启动。后续直接双击 TierFlow.app，可将它拖到 Dock 保留。
4. 这是未经过 Apple 公证的内部测试包。如果系统拦截安装脚本或应用，先尝试打开，再到「系统设置 → 隐私与安全性」选择「仍要打开」。仅在你信任此下载来源时确认，不需要关闭系统安全功能。
5. 首次启动可能提示访问登录钥匙串，请核对应用名 TierFlow。测试版升级重新签名后可能再次询问。

使用
跟随总览的「三步，开始智能路由」配置渠道、TierSense Key 和模型池。
点击红色关闭按钮后，已启动的服务继续运行；顶部菜单栏图标提供打开主界面、启动服务、停止服务、退出。
点击 Dock 图标恢复窗口。Command + 加号/减号调整界面缩放，Command + 0 恢复默认；Command + Q 完全退出，Command + W 收起窗口。
配置和加密密钥保存在 ~/Library/Application Support/TierFlow，删除应用不会删除它们。
升级前请从菜单栏完全退出 TierFlow，再运行新版本安装脚本。已有应用会备份到个人 Applications 目录，配置保留。

测试范围
本包在 Windows 上组装，保留 Mac 运行时、文件执行权限和框架符号链接；安装时由 Mac 的 codesign 对完整应用重新签名并验证。
尚未经 Mac 实机启动、钥匙串、菜单栏、缩放和真实渠道调用验收，不能当作已验收的官网正式版本。
TierFlow 账号登录、订阅购买仍待后端接入；已有 TierSense Key 可用于路由。
如失败，请保留安装窗口报错、Mac 芯片类型和 macOS 版本反馈；不要发送 API Key。
