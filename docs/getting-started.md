# 三步开始智能选模

## 安装前准备

- Windows x64 电脑。
- 你已购买的至少一个模型平台 API Key，且已开通准备使用的模型。
- TierSense 访问密钥，可在 [tierflow.cn](https://tierflow.cn) 获取。
- 支持 OpenAI Chat Completions 自定义接口的 AI 工具。

## 1. 连接服务

在总览点击配置引导的「连接服务」。选择渠道并填写密钥；渠道地址已按平台预置，使用代理或专属地址时再修改。获取模型列表后勾选需要的模型。列表获取失败时可以检查密钥、网络和平台权限，或手动输入真实模型 ID。

然后填写 TierSense 密钥。保存密钥本身不会产生模型调用费用；保存成功也不代表已通过真实调用验证。

## 2. 安排模型

先按综合难度划分档次，再在同档内安排模型分工。可以保留默认档次，也可以修改数量、名称和分界。

例如，两款模型都在旗舰档，可设置「编程较难时优先 GLM」「规划较难时优先 Qwen」。多条规则同时满足时按你设定的顺序选择；没有命中时按同档默认模型顺序。保存后新请求使用新配置。

向更高档次升级可能增加费用，可在路由设置中调整。工具和图片能力请按上游模型实际能力填写。

## 3. 连接 AI 工具

开启路由，将页面显示的三项信息复制到 AI 工具：

| 配置项 | 来源 |
| --- | --- |
| Base URL | 客户端显示的本地地址，默认是 `http://127.0.0.1:18420/v1` |
| API Key | 客户端生成的本地访问密钥 |
| Model | `tierflow-auto` |

本地访问密钥与模型平台密钥、TierSense 密钥各有用途。AI 工具中只填写客户端提供的本地密钥。

可以在客户端发起一次真实连接测试，该操作会使用 TierSense 和模型渠道，按对应服务规则消耗额度。日常直接在已连接的 AI 工具里提问即可。

## 之后在哪里修改

- 模型渠道：添加平台、修改密钥、查询支持的平台余额。
- 我的模型：增删模型、启停、搜索，查看档次与分工。
- TierSense 路由：修改档次、难度分界和同档分工。
- 连接 AI 工具：查看并复制三项接入信息。
- 使用记录 / 用量与费用：查看调用结果、Token、缓存与预估消费。

关闭窗口 × 会收起到托盘，服务继续运行。右下角图标可打开界面、启动/暂停服务或退出。升级前请选择「退出 TierFlow」。

## 常见问题

**模型显示“未开通”**：需要在该模型渠道开通对应产品或检查模型 ID；路由不能代替渠道授权。

**余额未显示**：只有支持的官方接口可查询。没有接口或没有返回数据时不会猜测余额。

**DeepSeek 多轮对话报 reasoning_content 缺失**：客户端可补回已捕获且可匹配的推理原文，但不能恢复升级前已经丢失或被大幅改写的历史。可先在新版运行期间新建对话验证，详见 [兼容说明](agent-compatibility.md)。

**费用比平台账单少**：客户端为估算，只覆盖有完整用量和单价的记录，不包含 TierSense、部分失败尝试、附加工具费或套餐优惠。

**仍无法使用**：通过仓库 Issues 提交脱敏问题，说明客户端与 AI 工具版本、渠道、模型 ID 和复现步骤。不要提供密钥或完整配置文件。
