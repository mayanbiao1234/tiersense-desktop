# TierFlow Desktop 0.4.10 · Windows 体验版

由 TierSense 决策模型驱动的个人桌面智能路由客户端。智能选模，搭配刚刚好。

## 下载

普通用户只需下载 Assets 中的 **TierFlow-Setup-0.4.10.exe**。无需下载 Source code，也无需安装 Node.js 或 Python。

适用 Windows x64。当前为未签名体验版；校验文件随 Release 提供。升级前请在右下角托盘退出旧版，新版沿用已有配置。

## 开始体验

准备模型渠道 API Key 与 TierSense 访问密钥（可在 https://tierflow.cn 获取），跟随总览三步引导：连接服务 → 安排模型 → 连接 AI 工具。

AI 工具仍只需填写 Base URL、API Key 和 `tierflow-auto`。模型费用由上游平台结算；TierSense 使用以官网和密钥权益为准，客户端内订阅购买尚未开放。

## 本次体验内容

- 管理多个模型渠道，自动获取模型列表，自定义档次和同档五维分工。
- 日常工作台、紧凑的渠道和模型列表、搜索筛选、未保存提醒及窗口位置记忆。
- 三步配置引导常驻显示在渠道、模型和用量卡片上方。
- 托盘启动/暂停服务、调用记录、Token/缓存信息、部分渠道余额和预估费用。
- WorkBuddy、OpenClaw、OpenCode 的 OpenAI Chat Completions 接入说明与后台推理历史兼容。

本次不提供 macOS 安装包。兼容情况受 AI 工具和上游版本影响，请通过仓库 Issues 反馈复现步骤；不要上传 API Key、完整配置文件或私密对话。
